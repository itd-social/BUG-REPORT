Репозиторий для сбора и отслеживания сообщений об ошибках (багах), найденных на платформе **[итд.com](https://xn--d1ah4a.com)**.

Этот репозиторий **не содержит кода** платформы — он служит единой точкой входа для багрепортов, которые затем передаются разработчикам ИТД в работу (если конечно они захотят их пофиксить)))

## Как сообщить о баге

1. Перейдите во вкладку **Issues**.
2. Проверьте поиском, не сообщал ли кто-то о такой же проблеме ранее.
3. Нажмите **New Issue** и выберите шаблон **🐞 Bug report**.
4. Заполните все поля формы как можно подробнее — это ускорит исправление.

Подробные требования к оформлению — в [CONTRIBUTING.md](./CONTRIBUTING.md).

## Статусы и лейблы

| Лейбл | Значение |
|---|---|
| `bug` | Подтверждённая ошибка |
| `needs-triage` | Новый репорт, ещё не проверен |
| `needs-info` | Не хватает данных для воспроизведения |
| `confirmed` | Баг воспроизведён разработчиком |
| `in-progress` | Взято в работу |
| `wontfix` | Не будет исправляться (с пояснением в комментарии) |
| `duplicate` | Дубликат другого issue |
| `priority: critical` | Платформа/ключевой функционал не работает |
| `priority: high` | Серьёзно мешает пользоваться |
| `priority: medium` | Заметный, но не блокирующий баг |
| `priority: low` | Косметическая проблема |

### Лейблы по области (опционально, можно проставлять после триажа)

| Лейбл | Значение |
|---|---|
| `area: frontend` | Веб-интерфейс |
| `area: backend` | API / серверная часть |
| `area: ios` | iOS-приложение |
| `area: android` | Android-приложение |

## Область ответственности

Репозиторий предназначен только для **багов** платформы итд.com. Предложения новых фич, вопросы по использованию и общие обсуждения сюда не относятся.
